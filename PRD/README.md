## 当前统一架构原则

```text
一个用户可以拥有多台设备
一台设备拥有一个 General 和多个专业 Agent
微信与 Matrix 可以作为同一 General 的不同入口
跨设备只能 General 调用 General
不同设备的 Agent 配置和数据默认互不共享
授权分为 agent_only 和 agent_and_data
AI 服务器负责管理平面，不转发正常模型任务
```

跨设备复用 Skills、Agent 定义和 SOUL 时，采用版本化发布和显式导入，
不采用实时目录或数据库同步。该能力在 V1 只预留设计和后台入口，不开放
实际分发操作。

## 图表格式

- 架构图、关系图、流程图和界面线框图优先使用 SVG。
- SVG 文件统一存放在 `PRD/assets/`。
- Markdown 使用相对路径引用 SVG，确保本地和 Git 平台均可查看。
- 数据表、权限矩阵、字段定义、需求条目和验收标准继续使用 Markdown。
- 不把长篇需求文字制作成 SVG，保证内容可搜索、可复制和便于审阅差异。

## SVG 要求

- 必须设置 `viewBox`，支持页面内缩放。
- 必须包含 `<title>` 和 `<desc>`，提供基本可访问性说明。
- 不依赖 JavaScript、远程图片、远程字体或外部样式。
- 使用明确的箭头、图例和边界颜色表达调用、管理、同步与禁止关系。
- 文字不得重叠、截断或超出容器。
- 提交前必须进行 XML 解析和实际渲染预览。
